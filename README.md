parts:
3x M5 screw
3x M5 bolt
1x M8 screw
1x M8 bolt
1x M6 screw (to mount your camera so it will depend on what camera you have)
1x M4 screw and bolt
1x Ø 20mm Aluminium tube 
1x Ø 33mm plastic tube
1x Logitech HD Pro Webcam C920 (or any other webcam but you will need to change one screw above)
